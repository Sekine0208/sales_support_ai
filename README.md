# 営業サポートAI プロジェクト

営業活動の効率化とKPI達成を支援するAIシステムです。

## 📋 プロジェクト概要

営業担当者の日々の活動を支援し、売上目標達成のために必要な行動KPIを管理・最適化するシステムです。

### コンセプト
- **指示だし**: KGI→KPI→Daily ToDoまで具体的な行動指示
- **補助輪**: 入力・思考時間を極小化する徹底的な操作支援
- **一気通貫**: 架電→訪問→商談→受注までのシームレス管理

## 🚀 クイックスタート

```powershell
# プロジェクトディレクトリへ移動
cd sales-ai-mock

# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:5173` にアクセスしてください。
