## 1. プロジェクト概要

### 1.1 プロジェクト名
営業サポートAI（Sales Support AI）

### 1.2 目的
営業活動を効率化するAIシステム。一気通貫の営業フロー管理とマネジメント機能を実現する高度なモックアップ版（実装進捗約85%）

### 1.3 開発背景
- **営業活動の属人化**: 成果のばらつきと標準化の必要性
- **顧客ニーズの把握タイミング**: 機会損失防止と効率的な情報収集
- **営業リソースの配分**: データ駆動による最適化の必要性
- **デジタル変革の要求**: 競合他社との差別化とプロセス改善

### 1.4 期待効果

#### モックアップ版からの継続効果
- **行動KPI達成率の向上**: 具体的指示により営業行動が明確化
- **営業効率の劇的改善**: 入力・思考時間の極小化により行動量確保
- **標準化された営業プロセス**: KGI→KPI→ToDoの一貫した指示だし
- **データ駆動営業**: 勘と経験に頼らない科学的営業手法の確立

#### 機能拡張版での追加効果
- **一気通貫管理**: 架電→訪問→商談→受注までの営業フロー全体をシームレス管理
- **マネジメント視点強化**: 10項目KPIの多軸分析による戦略的意思決定支援
- **AI自動判定**: 音声認識と自然言語処理による架電結果の自動入力で作業効率化
- **権限別最適化**: 営業担当者とマネージャーの役割に応じた機能提供

## 2. モック版前提・制約事項

### 2.1 モック版スコープ
| 機能分野 | モック版対応 | 制限内容 | 本格実装対応 |
|----------|--------------|----------|--------------|
| **フロントエンド** | ✅ 完全実装 | React SPAのみ | API連携対応 |
| **データ永続化** | ❌ JSONファイル | データ消失リスク | データベース連携 |
| **ユーザー認証** | ❌ 認証なし | セキュリティなし | 本格認証システム |
| **リアルタイム更新** | ❌ 手動更新 | 画面リロード必要 | WebSocket対応 |
| **外部システム連携** | ❌ 連携なし | 単体動作のみ | CRM・SFA連携 |
| **AI機能** | ❌ 静的データ | AI分析なし | 機械学習・予測 |
| **通知機能** | ❌ 通知なし | システム通知なし | メール・プッシュ通知 |

### 2.2 技術制約
- **ブラウザ環境**: Chrome, Edge, Safari (最新版)
- **画面解像度**: 1920x1080以上推奨
- **ネットワーク**: インターネット接続不要（ローカル実行）
- **デバイス**: PC・タブレット対応（スマートフォン未対応）
- **パフォーマンス**: 初期ロード3秒以内、操作レスポンス1秒以内

### 2.3 データ制限
- **サンプルデータ**: 実際のデータではなくダミーデータ使用
- **データ更新**: 手動更新のみ（自動更新なし）
- **データ量**: 1,000件以下のサンプルレコード
- **データ永続性**: セッション終了時にデータリセット

### 2.4 将来移行時の考慮点
- **データ移行**: JSONからDB移行プロセス要設計
- **API設計**: REST API仕様の定義が必要
- **認証フロー**: セキュリティ要件の詳細設計が必要
- **スケーラビリティ**: 大量データ対応のアーキテクチャ見直し

## 4. システム概要

### 4.1 システムコンセプト
**行動KPIを達成するところにとがらせたAI**
- **指示だし**: KGI→KPI→Daily ToDoまで落として具体的な行動を指示
- **補助輪**: ToDoを達成するための徹底的な支援（入力・思考時間の極小化）

### 4.2 基本方針
1. **シンプル・直感的**: 営業担当者が迷わず操作できるUI
2. **アクション指向**: 常に「次に何をすべきか」を明確に提示
3. **効率重視**: 無駄な入力・操作を徹底的に削減
4. **可視化**: KPI達成状況を一目で把握可能

### 4.3 主要機能（モック版）
1. **KPI指示だし機能** - メイン機能
2. **架電支援機能** - コア機能
3. **顧客リスト管理機能** - 補助機能
4. **簡易レポート機能** - 分析機能

## 5. 機能要件（モック版）

### 5.1 KPI指示だし機能

#### 5.1.1 概要
KGI→KPI→Daily ToDoまでブレークダウンして具体的な行動を指示

#### 5.1.2 詳細機能
- **KGI表示**: 月次売上目標・達成率をプログレスバーで表示
- **KPI表示**: 架電件数、アポ獲得数、提案件数を数値・グラフで表示
- **Daily ToDo生成**: 今日やるべき具体的行動リスト（優先度付き）
- **進捗トラッキング**: 行動KPI達成状況をリアルタイム表示
- **次アクション指示**: 未達成時の具体的な追加行動提案

#### 5.1.3 表示項目・UI要件
| 表示項目 | 形式 | 更新タイミング |
|----------|------|---------------|
| KGI達成状況 | プログレスバー（%表示） | 手動更新 |
| 行動KPI進捗 | 数値バッジ＋ミニグラフ | 手動更新 |
| 今日のToDo | チェックリスト（優先度色分け） | 手動更新 |
| 次にやること | アラートボックス（アクションボタン付き） | 手動更新 |
| 緊急度通知 | 警告アイコン・色変更 | 手動更新 |

#### 5.1.4 操作要件
- [ ] ToDoチェック：ワンクリックで完了切り替え
- [ ] アクション実行：ボタンクリックで関連画面へ遷移
- [ ] KPI更新：手動リフレッシュボタン
- [ ] 詳細表示：各KPIクリックで詳細グラフ表示

### 5.2 架電支援機能（最優先実装）

#### 5.2.1 概要
架電ToDoを達成するための徹底的な支援（入力・思考時間の極小化）

#### 5.2.2 詳細機能
- **架電リスト表示**: 優先度順の架電対象リスト表示
- **架電結果入力**: 固定選択項目による結果入力
  - 架電済/通電/アポ獲得/不在/拒否/その他（ラジオボタン）
  - 自由記入欄（任意）
- **顧客詳細ポップアップ**: モーダル形式での詳細情報表示・編集
  - 基本情報・BANTC情報・活動履歴をタブ表示
- **BANTC情報管理**: AIたたき台+自由記入による情報管理
  - Budget（予算）: プルダウン+詳細入力
  - Authority（決裁権）: プルダウン+決裁者入力
  - Need（課題・ニーズ）: 自由記入+AI分析結果表示
  - Timeline（導入時期）: プルダウン+日付選択
  - Competition（競合情報）: 自由記入
- **活動履歴表示**: 過去1年分の時系列活動履歴表示

#### 5.2.3 表示項目・UI要件
| 表示項目 | 形式 | 動作 |
|----------|------|------|
| 架電リスト | テーブル（優先度順ソート） | 20件/ページ |
| 架電結果選択 | ラジオボタン（固定6項目） | 必須選択 |
| 詳細記入欄 | TextArea | 任意入力 |
| 顧客詳細ボタン | ボタン | ポップアップ表示 |
| 活動履歴 | Timeline形式（next_order.md準拠） | モーダル内表示 |
| BANTC情報 | フォーム+AI表示 | モーダル内編集 |

#### 5.2.4 操作要件
- [ ] 架電先選択：テーブル行クリックで詳細ポップアップ表示
- [ ] 架電結果入力：ラジオボタン選択+自由記入（任意）
- [ ] 顧客詳細表示：「詳細」ボタンクリックでモーダル表示
- [ ] BANTC情報編集：モーダル内でのフォーム入力・編集
- [ ] 活動履歴確認：過去1年分の時系列表示（next_order.md 51-54行目準拠）
  - [ ] 各活動は「架電結果項目選択」＋「自由記入欄」で1行ずつ表示
  - [ ] 時間軸順（最新が上）の縦並び表示
  - [ ] 活動種別（架電・訪問・見積・商談）をアイコンと色で区別
  - [ ] 履歴データは参照のみ（編集不可）
- [ ] 自動連携：アポ獲得選択時の訪問リスト自動追加

### 5.3 活動履歴表示機能（next_order.md 51-54行目準拠）

#### 5.3.1 概要
企業名をクリックした時の右側企業情報表示で、過去1年分の活動履歴を時間軸順に表示

#### 5.3.2 詳細機能
- **表示期間**: 過去1年分の全活動履歴
- **表示順序**: 時間軸順（最新の活動が上）
- **活動種別**: 架電・訪問・見積・商談の全活動
- **結果項目表示**: 各活動の結果項目を固定選択項目形式で表示
- **詳細内容表示**: 自由記入欄の内容をテキストエリア形式で表示
- **編集権限**: 履歴データは参照のみ（過去データ編集不可）

#### 5.3.3 表示項目・UI要件
| 表示項目 | 形式 | 内容 |
|----------|------|------|
| 活動日時 | ラベル | YYYY/MM/DD HH:MM形式 |
| 活動種別 | アイコン+色 | 架電（📞緑）・訪問（👤青）・見積（📄橙）・商談（💼紫） |
| 結果項目 | セレクトボックス（無効化） | 各活動種別に応じた固定選択項目 |
| 詳細内容 | テキストエリア（無効化） | 自由記入欄の内容を表示 |
| 担当者 | テキスト | 活動実施者名 |
| タグ表示 | バッジ | 活動結果の視覚的表示 |

#### 5.3.4 活動種別・結果項目対応
| 活動種別 | 結果項目選択肢 | 色分け |
|----------|----------------|--------|
| **架電** | 架電済/通電/アポ獲得/不在/拒否/その他 | 緑系 |
| **訪問** | 成功/一部成功/失敗/再訪問必要 | 青系 |
| **見積** | 下書き/提出済み/承認/却下/期限切れ | 橙系 |
| **商談** | 進行中/見積提出/検討中/条件調整/受注/失注 | 紫系 |

#### 5.3.5 操作要件
- [ ] 活動履歴一覧：Timeline形式での縦並び表示
- [ ] 結果項目確認：各活動の結果項目を無効化セレクトボックスで表示
- [ ] 詳細内容確認：自由記入欄の内容を無効化テキストエリアで表示

## 6. 機能要件（拡張版）

### 6.1 Phase 7: マネジメントダッシュボード（優先度1）

#### 6.1.1 KPI一覧表示機能
- **対象KPI**: 架電数、通電数、アポ獲得数、訪問数、商談数、商談単価、受注件数、受注単価、失注件数
- **表示形式**: テーブル形式、ソート・フィルタリング対応
- **達成率表示**: 色分け表示（目標達成度による）
- **権限**: マネージャーのみアクセス可能

#### 6.1.2 分析軸フィルター機能
- **時間軸**: 日付範囲選択（最大過去1年間）
- **自社軸**: 部署別、営業担当別、商材別
- **顧客軸**: 企業規模別、業界別、新規/既存別
- **分析軸**: 平均値、中央値、上位5人、下位5人

#### 6.1.3 チャート表示機能
- **KPIトレンドグラフ**: 時系列推移表示
- **営業ファネル**: 各工程の通過率可視化
- **部署別比較**: 横並び比較チャート

### 6.2 Phase 8: 営業フロー拡張（優先度2）

#### 6.2.1 サイドメニュー拡張
- **メニュー項目**: KPI指示だし、架電、訪問、商談、受注
- **ナビゲーション**: サイドメニューでのページ遷移
- **権限制御**: 営業担当者は全機能利用可能、マネージャーは追加で他人データ閲覧可能

#### 6.2.2 訪問管理機能
- **訪問対象リスト**: アポ獲得済み顧客の自動表示
- **訪問予定管理**: 日程・時間・場所の管理
- **訪問結果入力**: 商談発生フラグ設定
- **自動連携**: 商談発生時に商談リストへ自動追加

#### 6.2.3 商談管理機能
- **商談リスト**: 月別表示、過去履歴閲覧可能
- **商談詳細**: 進捗状況、見積情報、受注見込み確度
- **商談単価算出**: 受注見込み金額（確度×見積金額）
- **結果管理**: 見積・受注・失注の結果入力

#### 6.2.4 受注履歴機能
- **受注実績**: 月別受注実績表示
- **金額集計**: 受注金額・商材別集計
- **履歴検索**: 期間・条件別検索機能

### 6.3 Phase 9: データフロー連携（優先度3）

#### 6.3.1 AI自動判定機能
- **音声認識**: 架電内容の自動テキスト化
- **結果判定**: 自然言語処理による通電・アポ獲得の自動判定
- **手動修正**: AI判定結果の人間による修正機能
- **アポ定義**: 担当者との次回話し合いの約束ができた場合をアポ獲得とみなす

#### 6.3.2 工程間自動連携
- **架電→訪問**: アポ獲得時の自動訪問リスト追加
- **訪問→商談**: 商談発生時の自動商談リスト追加
- **商談→受注**: 受注決定時の自動受注データ生成

#### 6.3.3 状態管理基盤
